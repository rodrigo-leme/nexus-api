Quem Somos

Fundada em 2024, a Space Code LTDA nasceu com uma missão ousada: desenvolver software resiliente para os ambientes mais extremos do planeta — e fora dele. Após anos atendendo plataformas offshore, bases de pesquisa polar e operações de defesa, fomos selecionados para sermos uma das primeiras empresas do mundo a manter uma réplica exata de nossa infraestrutura em um datacenter espacial, garantindo recuperação de desastres com zero emissão de carbono e refrigeração no vácuo.

Nossa infraestrutura terrestre roda sobre Windows Server com Active Directory, DNS e IIS, espelhada continuamente para o nosso recovery site orbital.
